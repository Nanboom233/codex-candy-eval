# v0.2.16 Prebuilt Delivery Check Review

## Findings (fixed)

- File: `cleanup.py`
- Issue: The no-follow path-stat call used during temporary-workspace removal was not compatible with the installer’s Python 3.9 minimum.
- Fix: The implementation replaced that call with `Path.lstat()` and rebuilt the archive. The current source and final archive use the compatible form.
- File: `cleanup.py`
- Issue: `cleanup.command` did not relay partial stdout/stderr attached to `subprocess.TimeoutExpired`.
- Fix: It now relays the original byte streams and re-raises the same timeout exception. A shared relay also keeps nonzero-exit output to one copy. The regression runs a real fake-Docker child, times it out after writing 12 KB to both streams, and verifies the exception bytes and emitted output; it also checks a normal nonzero exit is relayed once. The test deadline is five seconds so scheduler load does not cause a false failure.
- File: `scripts/package-sub2api.py`
- Issue: Release creation used host `tar` on the staged directory. The raw archive included AppleDouble entries that the BSD `tar` listing hid, so the exact eight-file payload check was false.
- Fix: The packager now writes deterministic USTAR/gzip members from the explicit allowlist and validates raw names, types, sizes, content, duplicates, and extended metadata. README and CI use this archive writer. A raw-tar round-trip test checks an xattr-bearing source when supported and passes the archive through installer extraction.
